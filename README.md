# جدولي

جداول محاضرات الأكاديمية الحديثة بالمعادي — موقع ثابت (HTML/CSS/JS) منشور على Firebase Hosting، والبيانات والدخول على Supabase.

## التشغيل والفحص

```bash
npm start        # يشغّل الموقع محليًا على http://localhost:8080
npm run check    # فحص قبل النشر: صحة ملفات JS، الملفات المذكورة في الصفحات والـ service worker، اتجاه الـ CSS، واختبارات محرك الجداول
npm test         # اختبارات محرك فهم الجداول بس (tools/test-parser.mjs)
firebase deploy  # النشر
```

مفيش خطوة build: الملفات بتتنشر زي ما هي.

## بنية المشروع

| المسار | الوظيفة |
| --- | --- |
| `css/tokens.css` | نظام التصميم المشترك: الألوان (فاتح/داكن)، الخط، المسافات، الأزرار، الإشعارات، النوافذ، هياكل التحميل |
| `css/styles.css` | موقع الطلبة |
| `js/theme.js` | بيطبّق الوضع المحفوظ قبل الرسم |
| `js/ui.js` | `UI.toast` و `UI.confirm` و `UI.empty` ومفتاح الوضع — مشترك مع لوحة الإدارة |
| `js/app/core.js` | البيانات، الحالة، أدوات الوقت، البحث |
| `js/app/views.js` | كل الصفحات والتنقل والمسارات |
| `js/app/assistant.js` | مساعد «اسأل جدولي» |
| `js/app/share.js` | صور الجدول، CSV، ICS، الطباعة، لينك الفصل |
| `js/app/push.js` | الإشعارات |
| `js/app/sync.js` | المزامنة مع Supabase والتحديث اللحظي |
| `js/app/events.js` · `boot.js` | ربط الأحداث والتشغيل |
| `admin/core.js` · `panels.js` · `actions.js` · `main.js` | لوحة الإدارة |
| `admin/parser.js` | محرك فهم الجداول: دوال صافية بتحوّل صفوف نص بأي شكل لمحاضرات/امتحانات بصيغة جدولي |
| `admin/importer.js` | استخراج الصفوف من PDF (نص + خطوط الجدول)، الصور (OCR)، Excel و CSV |
| `admin/review.js` | شاشة «راجع ونسّق قبل النشر» |
| `sw.js` | العمل بدون إنترنت والإشعارات |

ترتيب ملفات `js/app/` في `index.html` مهم: كلها سكربتات عادية بتشارك نفس النطاق.
لما تضيف ملف جديد لموقع الطلبة ضيفه في `FILES` جوه `sw.js` وزوّد رقم `CACHE` — `npm run check` بينبّهك لو نسيت.

## قواعد التصميم

- استخدم متغيرات `tokens.css` بدل الألوان والمقاسات المباشرة.
- خصائص منطقية بس (`inline-start` / `inline-end`) عشان الـ RTL.
- أقل مساحة لمس 44px على شاشات اللمس.

## رفع الجداول (لوحة الإدارة)

1. **الاستخراج** (`importer.js`): نص الـ PDF بيتقري مباشرة ويتركّب على خطوط الجدول المرسومة (عشان الخانات المدموجة). الصور والـ PDF المتصوّر بيتقروا خانة خانة بقارئين (عربي + إنجليزي) وكل سطر بيتاخد من الأوثق.
2. **الفهم** (`parser.js`): خمس استراتيجيات (شبكة أيام×مواعيد بالاتجاهين، قائمة بعناوين، صفوف حرة، سطور متتابعة) والأنضف هي اللي بتكسب.
3. **المراجعة** (`review.js`): مفيش حفظ غير بعد التأكيد. النشر بيستبدل جدول كل فصل ظاهر في الصفوف.

- المكتبات (pdf.js / tesseract.js / xlsx) بتتحمّل من الـ CDN وقت الحاجة بس.
- لو غيّرت مصدر مكتبة أو ملفات لغة الـ OCR راجع الـ `Content-Security-Policy` في `firebase.json` (`script-src` لازم فيه `'wasm-unsafe-eval'`).
- نوع الحصة (سكشن / معمل) مالوش عمود في القاعدة، فبيتحفظ في عمود `note` الموجود ويظهر للطالب كملاحظة (ممكن يتقفل من شاشة المراجعة).

## دوال Supabase

| الدالة | الوظيفة | التحقق |
| --- | --- | --- |
| `jadwali-assistant` | «اسأل جدولي» للطلبة | مفتوحة (`verify_jwt: false`) ومقصورة على عنوان الموقع |
| `jadwali-import` | قراءة الجداول المرفوعة بالذكاء الاصطناعي في لوحة الإدارة | لازم جلسة أدمن فعّالة (`verify_jwt: true` + فحص `profiles`) |

الاتنين بيستخدموا سر `GROQ_API_KEY`. قوائم الموديلات في أول كل ملف لازم تكون من الموديلات المتاحة فعلًا على حساب Groq.
